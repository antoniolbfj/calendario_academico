Ativar Agenda Pública

1
Crie o projeto no Google Cloud e registre o número

Primeiro crie o projeto Cloud. Só depois copie o Número do projeto e registre-o aqui. O sistema usará esse número como referência oficial durante toda a ativação.

Google Cloud · Novo projeto
Nome do projeto
GERADOR DE CALENDÁRIOS
Depois de criar, copieNúmero do projeto
Exemplo: 316494636147 · somente números
  1. Clique em Criar projeto no Google Cloud.
  2. Informe um nome, por exemplo GERADOR DE CALENDÁRIOS, e clique em Criar.
  3. Abra o projeto criado e localize Número do projeto.
  4. Copie somente o número e cole no campo abaixo.
1. Criar projeto no Google Cloud
—
O número registrado não será trocado automaticamente pelo sistema. Se o Google mencionar outro projeto durante o diagnóstico, a divergência será apenas informada para você corrigir.
2
Associe o projeto Cloud ao Apps Script

Agora informe ao Apps Script qual projeto Google Cloud ele deve usar. Essa associação é necessária antes de ativar as APIs.

Apps Script · Configurações do projeto
⚙ Configurações do projeto → Projeto do Google Cloud Platform (GCP)
Projeto registrado—
Alterar projeto
  1. Clique em Abrir projeto no Apps Script.
  2. No menu esquerdo, clique na engrenagem ⚙ Configurações do projeto.
  3. Localize Projeto do Google Cloud Platform (GCP) e clique em Alterar projeto.
  4. Cole o mesmo número registrado na etapa 1 e confirme.
  5. Se o Google solicitar nova autorização depois da associação, conclua-a com a mesma conta.
Abrir projeto no Apps Script
3
Ative as três APIs no projeto correto

Abra cada API pelos botões abaixo. Os links são fixados ao número registrado na etapa 1. Em cada página, clique em Ativar. Se aparecer API ativada ou o botão Gerenciar, ela já está pronta.

Google Apps Script APIUsada para localizar a implantação institucional.Abrir Apps Script API
Google Calendar APICria, lê e sincroniza a Agenda Pública.Abrir Calendar API
Gmail APIUsada nas comunicações institucionais da Agenda Pública.Abrir Gmail API
Registre o número do projeto na etapa 1 para que os links sejam abertos no projeto Cloud correto.
4
Permita que a Apps Script API acesse seus projetos

Esta configuração é diferente de ativar a API no Google Cloud. Ela pertence à sua conta Apps Script.

Apps Script · Configurações
Google Apps Script APIAtivado
Ative a opção que permite que aplicativos externos acessem seus projetos Apps Script.
  1. Clique em Abrir configurações da Apps Script API.
  2. Localize a opção Google Apps Script API.
  3. Ative o controle de acesso aos seus projetos.
Abrir configurações da Apps Script API
5
Se o Google mostrar erro 403, autorize sua conta de teste

Esta etapa só é necessária se aparecer Erro 403: access_denied ou uma mensagem dizendo que o aplicativo está em fase de testes.

Google Auth Platform · Público-alvo
Público-alvo → Usuários de teste
Adicionar usuários
Adicione o mesmo e-mail que está executando o sistema.
  1. Abra Google Auth → Público-alvo.
  2. Localize Usuários de teste.
  3. Clique em Adicionar usuários e informe a conta que está fazendo a ativação.
  4. Salve. Não crie credenciais OAuth manualmente apenas por causa desse aviso.
Abrir Google Auth → Público-alvo
6
Crie a implantação institucional como App da Web

Esta implantação executa as operações da Agenda Pública. Use exatamente as opções abaixo.

Apps Script · Nova implantação
Implantar → Nova implantação → ⚙ Selecionar tipo → App da Web
DescriçãoAGENDA PÚBLICA — GERADOR DE CALENDÁRIOS
Executar comoEu
Quem pode acessarQualquer pessoa
Implantar
  1. Clique em Abrir projeto no Apps Script.
  2. No canto superior direito, clique em Implantar → Nova implantação.
  3. Clique na engrenagem ⚙ ao lado de “Selecione o tipo” e escolha App da Web.
  4. Em Descrição, informe AGENDA PÚBLICA — GERADOR DE CALENDÁRIOS.
  5. Em Executar como, escolha Eu.
  6. Em Quem pode acessar, escolha Qualquer pessoa.
  7. Clique em Implantar e autorize, se solicitado.
Abrir projeto no Apps Script
Não é necessário copiar a URL exibida pelo Google. Se já existir uma implantação, atualize a implantação existente em Implantar → Gerenciar implantações → Editar → Versão: Nova versão.
7
Conferir e concluir a ativação

Agora o sistema fará somente o diagnóstico final: autorização, associação do projeto, acesso da Apps Script API, implantação e Google Calendar API. Nenhum número de projeto será alterado automaticamente.
